# Changelog

All notable changes to this project will be documented in this file.

## [2.0.0] - 2024-XX-XX

### Added

- React 19 compatibility
- New `createCompatibleTheme` function for React 19 support
- Dual support for both React 18 and React 19

### Changed

- Updated peer dependencies to support React 19
- Migrated from React.FC type to standard function components
- Updated Vite React plugin to latest version

### Fixed

- Improved TypeScript integration with React 19

## [1.0.2] - Previous version

Initial release with Material You theme support for MUI v7 and React 18.
